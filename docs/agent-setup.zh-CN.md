# Agent 安装指南

[English](agent-setup.md) | 简体中文

本文档供被要求把用户电脑配置成本地 Agent 环境的编码 Agent 使用。目标是根据
用户实际硬件和偏好完成经过验证的安装，而不是复制基准机器。

## 安装原则

- 先检查，再安装。
- 下载模型权重前先询问用户。
- 仓库中的 Qwen、Gemma、DeepSeek 等名称只是建议，不是默认选项。
- 只安装用户明确选择的后端、模型和 Agent CLI。
- 保留现有磁盘、文件、凭据和 Agent 配置。
- 最后执行端到端测试并给出简洁报告。

在用户选择模型类别并确认预计下载大小前，不要执行 README 中的示例下载。

## 1. 检查机器

收集以下信息：

- 操作系统和架构；
- CPU 型号、核心数和线程数；
- 系统内存；
- GPU 型号、显存和驱动版本；
- 目标模型卷的可用空间；
- Python、Git、CMake、CUDA 和 NVIDIA 驱动；
- 现有的 `llm`、`codex`、`claude`、`hermes` 和 `ollama` 命令；
- 已安装模型和未完成的 `.part` 下载。

常用命令：

```text
llm doctor
llm paths
llm models
```

Windows 可使用 `Get-CimInstance`、`nvidia-smi` 和 `Get-PSDrive`；Linux 可使用
`lscpu`、`free -h`、`nvidia-smi` 和 `df -h`。无法读取的项目应标记为未知，
不要猜测。

## 2. 判断硬件档位

有可用加速器时优先参考显存，否则参考系统内存。模型还必须为 KV cache、计算
缓冲区、操作系统和其他应用留出空间。

| 可用内存 | 初始建议 | 说明 |
|---|---|---|
| 仅 CPU，8 GB RAM 以下 | Qwen3.5-2B Q4 | 使用较短上下文和精简工具集 |
| 6-8 GB 显存 | Qwen3.5-2B 或 Qwen3.5-4B Q4 | 长上下文或低延迟优先选 2B |
| 10-12 GB 显存 | Qwen3.5-4B Q4 | 平衡的 Agent 编码起点 |
| 14-16 GB 显存 | Qwen3.5-4B/9B、Gemma E4B | 更大的模型取决于 RAM 和上下文 |
| 24 GB 显存以上 | 9B-14B | 选择能通过冒烟测试的最大模型 |

这些只是起点，不是硬性兼容承诺。模型架构、上下文长度、KV cache 类型和
Agent 自身提示开销都会影响实际占用。

## 3. 询问用户

在建议下载前，先问：

> 本地模型最需要优化什么：平衡编码、最快响应/最低内存、通用助手、最高
> 质量，还是暂时不安装模型？准备使用 Codex、Claude Code 还是 Hermes？

给出少量兼容建议及大小、取舍：

- **平衡编码：** Qwen3.5-4B Q4_K_M。
- **快速/低内存：** Qwen3.5-2B Q4_K_M。
- **通用助手：** Gemma 4 E4B QAT（硬件空间足够时）。
- **更高质量：** Qwen3.5-9B 或已验证的 14B 选项，并说明上下文和内存代价。

不要脱离用户目标直接标记“推荐”。等待答案期间不要开始数 GB 的下载。

非交互环境中，在展示硬件评估和选项后停止。没有回答不代表可以安装。

## 4. 确认方案

每个候选模型都应说明：

- 精确模型 ID 和量化格式；
- 来源仓库和许可证；
- 下载大小；
- 运行后端；
- 大致内存和上下文影响；
- 发布方提供的校验和；
- 为什么适合用户目标。

然后请用户选择一个模型，或明确暂缓模型安装。

## 5. 安装后端和 Agent

llama.cpp 是主要验证后端。Agent CLI 单独安装。

Windows 上没有 CUDA 编译器时，优先使用仓库记录的预编译 CUDA 方案；缺少
`nvcc` 不妨碍使用预编译 CUDA 运行时。

安装前检查现有 Agent：

```text
codex --version
claude --version
hermes --version
```

询问用户准备使用哪个 Agent，不要默认安装全部三个。

## 6. 只安装选中的模型

先查看存储路径：

```text
llm paths
```

下载到 `.part` 文件，支持续传，并在完整大小和 SHA-256 匹配后才重命名。
最终报告中记录来源和校验和。

不要格式化模型磁盘、用未完成文件覆盖完整模型、未经同意删除现有模型，或把
权重放进 Git 仓库。

## 7. 端到端验证

运行：

```text
llm doctor
llm models
llm start
```

确认：

1. 后端健康；
2. `/v1/models` 返回所选模型；
3. 一次短聊天请求成功；
4. 所选 Agent 能通过本地包装命令启动；
5. `<think>` 等控制标记不会泄漏到用户可见文本；
6. Agent 启动后保留调用目录。

仅用于测试的服务器完成后应停止，除非用户要求保持运行。

## 8. 报告结果

报告硬件、后端、Agent CLI、模型、大小、路径、校验和状态、上下文和
GPU/CPU 分配、验证结果，以及未安装的可选组件。

端到端测试通过前不要宣称“已经可用”。

## 恢复和安全

可移动 Linux 文件系统突然消失时，停止写入并保留磁盘。不要为了在 Windows
中重新访问而格式化它。先进行只读检查，必要时再使用该文件系统的原生修复工具。
